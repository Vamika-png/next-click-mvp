# Guide: build an automation (Zapier or Make): "when this happens, do that"

Use this guide when the user's goal is to automate something: connect two apps, move information between them automatically, send a message when something happens, or save files automatically. Two websites do this for beginners: Zapier (zapier.com) and Make (make.com). Pick one and keep it for the whole job: Zapier is simpler for a first automation; Make gives more for free. Screens change often, so trust the page over this guide and set verified false for any button name you are not sure about.

Goal state: the automation is switched ON, and a test run worked.

## The idea, in simple words
An automation has two parts. A **trigger** is the thing that starts it ("a new email arrives"). An **action** is what happens next ("save the file in Drive"). Say this in one simple sentence the first time, in the note.

## Steps
1. **Sign up.** The user is new. Prefer "Sign up", "Get started" or "Start free", and "Continue with Google" on the next screen. Never ask for a password.
2. **Start a new automation.** Zapier: the "Create" button (a "Zap" is an automation). Make: "Create a new scenario" (a "scenario" is an automation).
3. **Choose the trigger app.** Search for the app that starts it (for example Gmail). Choose the event that matches, such as "New Email", "New Attachment" or "New Row".
4. **Connect the account.** A "Sign in" or "Connect" button opens a Google or app window. The user approves access themselves. Never ask them to share a password or key.
5. **Test the trigger.** Press "Test" or "Run once" so the tool finds a real example.
6. **Choose the action app.** Search for the app that does the work (for example Google Drive) and choose the event, such as "Upload File" or "Create Row". Connect that account the same way.
7. **Fill in the details.** The tool shows boxes. Choose items from its pick-list (for example the attachment from the trigger). If the user must type something, say which box and what to type, using copyText when it is longer than a few words.
8. **Test the whole thing**, then switch it ON ("Publish", "Turn on", or a switch at the bottom left).
9. Done when the automation shows as ON.

## Notes
- Free plans have limits that change. If the page says a step needs a paid plan, say so in the note and suggest the other tool or a simpler automation.
- You cannot point at things inside a drop-down picker that draws itself; describe them in words.
