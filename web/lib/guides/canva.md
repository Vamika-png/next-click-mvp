# Guide: make a design in Canva (poster, Instagram post, flyer, logo, presentation)

Use this guide when the user's goal is a poster, social media post, flyer, logo, card or slides, or anything made in Canva. Canva is a website: canva.com.

Goal state: the finished design is downloaded as a picture or PDF (or shared as a link).

## Steps
1. **Sign in.** The user is probably new. Prefer "Sign up" or "Continue with Google"; never ask for a password.
2. **Start a design.** On the home page, press the "Create a design" button (usually at the top right) or use the search box that says something like "What will you design today?". Pick the size that matches the goal, for example "Instagram Post", "Poster", "Flyer", "Logo" or "Presentation".
3. **Pick a template.** The editor opens with a left panel. Find the "Templates" tab, scroll through, and press one that looks close to what the user wants. A search box in that panel lets them type words like "sale" or "festival".
4. **Change the words.** Double-click the text on the design, select it, and type new words. You cannot point at text inside the design itself because it is drawn on a canvas; describe where it is in words ("the big words in the middle").
5. **Change pictures and colours.** Use the left panel tabs: "Elements" (shapes and stickers), "Uploads" (the user's own photos), "Text". Click a picture on the design, then use the toolbar that appears above it.
6. **Download.** Press the "Share" button at the top right, then "Download". Choose "PNG" for a picture or "PDF", then press "Download".
7. Done when the file has downloaded or the user is looking at the finished design they are happy with.

## Notes
- Canva marks some templates and elements with a crown. Those need a paid plan; suggest a different one without the crown.
- Button names change often. Trust the page over this guide and set verified false for any name you are not sure about.
- For anything inside the design (a word, a picture), set elementId to null and say where it is in simple words.
